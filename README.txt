Previsão do Tempo no Terminal

Este programa pega o pais e a cidade que voce escrever no cmd e te mostra o clima dessa regiao

Pré-requisitos
 Python (versão 3.8 ou superior recomendada)
  Para verificar se você já tem o Python instalado, execute o seguinte comando no seu terminal: python --version
  (Caso não tenha, faça o download e a instalação em python.org.)
 Pycountry e Requests
  Para instalar digite isso no seu cmd: pip install requests pycountry
